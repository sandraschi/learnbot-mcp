# دليل الاندماج — تعلّم الألمانية للناطقين بالعربية

**learnbot-mcp**: نظام مفتوح المصدر لتعلم اللغات باستخدام الذكاء الاصطناعي. صُمّم خصيصاً لمساعدة المتحدثين بالعربية على تعلّم اللغة الألمانية للحياة اليومية في النمسا.

> هذا المشروع مستقل وغير تابع لأي جهة حكومية. يمكن استخدامه مجاناً بالكامل.

---

## لماذا هذا النظام مختلف؟

| المهارة | كورسات الاندماج التقليدية | learnbot-mcp |
|---------|--------------------------|-------------|
| **المحادثة** | محدودة بوقت الحصة | غير محدودة — تحدث مع ليلى بالعربية والألمانية |
| **التصحيح** | مرة واحدة في الأسبوع | فوري — يصحح الجملة فور كتابتها |
| **المفردات** | قوائم ثابتة | تكرار متباعد حسب مستواك (SM-2) |
| **القراءة** | نصوص جاهزة | نصوص مُدرَّجة حسب مستواك مع أسئلة |
| **السعر** | 500-2000 يورو لكل مستوى | مجاني (يعمل على حاسوبك الشخصي) |
| **الخصوصية** | بياناتك عند المعهد | كل شيء على جهازك — لا خادم مركزي |

## كيف يعمل

### 1. إنشاء الشخصية المساعدة

شخصية "ليلى" — مدرّبة ثنائية اللغة (عربي/ألماني) تفهم الثقافة النمساوية:

```
persona_create(
  name="layla",
  display_name="ليلى",
  backstory="أنت مدرّسة ألمانية-عربية. تساعدين المتحدثين بالعربية على
    تعلم الألمانية للحياة اليومية في النمسا. تشرحين القواعد بالعربية.
    تتقنين مواضيع: Meldezettel، AMS، Arztbesuch، Wohnungssuche، Supermarkt.
    صبورة ومشجعة.",
  voice="Leda",
  languages=["ar","de"],
  skills=["vocab_quiz","grammar_check","reading_passage","graded_reader"]
)
```

### 2. بدء محادثة

```
chat_start(persona="layla", platform="opencode", user_id="your-name")
chat_send(conversation_id="abc123", content="مرحبا ليلى، أريد أن أتعلم كيف أقدم نفسي بالألمانية")
```

### 3. دروس منظمة

```
# إنشاء درس في مستوى A1
lesson_generate(title="التعريف بالنفس", language="de", level="A1", framework="CEFR")

# تشغيل الدرس في المحادثة
lesson_run(lesson_id=1, conversation_id="abc123")

# الآن ليلى تدرّسك والردود تكون ضمن الدرس
chat_send(conversation_id="abc123", content="Ich verstehe nicht, wann man 'du' und 'Sie' sagt")
```

### 4. قراءة مُدرَّجة (Graded Reader)

نصوص مفهومة حسب مستواك مع كلماتها الرئيسية وأسئلة الفهم:

```
# قصة عن موضوع الحياة اليومية
graded_reader(language="de", level="A1", target_lang="ar", topic="beim Arzt")

# قصة عن السكن
graded_reader(language="de", level="A2", target_lang="ar", topic="Wohnungssuche")
```

### 5. تصحيح القواعد الفوري

اكتب جملة بالألمانية واحصل على التصحيح مع الشرح بالعربية:

```
grammar_check(text="Ich gehen zum Supermarkt.", source_lang="de", target_lang="ar")
# → "Ich gehe zum Supermarkt." مع شرح قاعدة تصريف الأفعال بالعربية
```

### 6. تكرار المفردات (Spaced Repetition)

النظام يتذكر الكلمات التي تتعلمها ويختبرك فيها في الوقت المناسب:

```
vocab_quiz(source_lang="de", target_lang="ar", count=5)
vocab_submit(word="der Termin", correct=True)
```

## مواضيع الحياة اليومية في النمسا

النظام يُدرّس اللغة في سياق الحياة الواقعية:

| الموضوع | الجملة الأساسية | الدرس |
|---------|----------------|-------|
| **Meldezettel** (التسجيل) | "Wo muss ich mich anmelden?" | `graded_reader(topic="Meldezettel")` |
| **AMS** (سوق العمل) | "Ich suche einen Job." | `lesson_generate(title="Arbeitssuche in Österreich")` |
| **Arztbesuch** (الطبيب) | "Ich habe Schmerzen." | `graded_reader(topic="beim Arzt")` |
| **Wohnungssuche** (السكن) | "Ich suche eine Wohnung." | `graded_reader(topic="Wohnungssuche")` |
| **Supermarkt** (السوبرماركت) | "Wo finde ich das Brot?" | `vocab_quiz(topic="Lebensmittel")` |
| **Öffis** (المواصلات) | "Einmal nach Wien, bitte." | `lesson_generate(title="öffentliche Verkehrsmittel")` |
| **Behorde** (الدوائر الرسمية) | "Ich habe einen Termin." | `graded_reader(topic="Amtsweg")` |

## متطلبات التشغيل

لتشغيل النظام على حاسوبك:

1. **Ollama** — لتشغيل نموذج الذكاء الاصطناعي محلياً
   - حمّل من: https://ollama.com
   - شغّل النموذج: `ollama run gemma4:12b` (يدعم العربية جيداً)

2. **Python 3.12+** و **uv** — لتشغيل النظام
   ```
   uv sync
   uv run python -m learnbot_mcp.api
   ```

3. **متصفح** — لفتح واجهة المستخدم على http://127.0.0.1:11102

> **ملاحظة:** كل شيء يعمل على جهازك — لا نحتاج إلى اتصال بالإنترنت بعد تحميل النموذج.
> هذا يعني أن بياناتك لا تُرسل إلى أي خادم خارجي.

## ماذا يحتاج النظام ليكون جاهزاً للاستخدام الواسع؟

1. **منهاج اندماج نمساوي** — دروس مبنية على منهاج ÖIF الرسمي لمستويات A1-B1
2. **مفردات متخصصة** — كلمات وجمل خاصة بالاندماج (Meldezettel، Niederlassungsbewilligung، إلخ)
3. **نطق** — تحسين اللفظ باستخدام تقنية التعرف على الكلام (speech-mcp)
4. **تقييم** — اختبارات تحديد مستوى تتوافق مع ÖIF
5. **تطبيق جوال** — ليس فقط متصفح

هذه التحسينات ممكنة مع تمويل أو شراكة مع مؤسسات مثل SOS Mitmensch أو Österreichischer Integrationsfonds.
